# GitHub publication checklist

1. Create a repository named `qyra-lang`.
2. Upload the contents of this directory, not the outer archive folder.
3. Keep the repository description factual: `Experimental Qyra compiler and bytecode VM`.
4. Create tag `v0.3.0-alpha.1`.
5. Attach the release ZIP.
6. Mark the GitHub release as a pre-release.
7. Do not describe this build as production-ready or as a replacement for Python/C++.
