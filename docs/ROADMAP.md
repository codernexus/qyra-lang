# Roadmap

- 0.4: lexical scopes, `for`, collections, indexing, `break`/`continue`.
- 0.5: modules, `struct`, `enum`, `Option`, `Result`, pattern matching.
- 0.6: standard library foundations, files, paths, JSON, testing.
- 0.7: SQLite/PostgreSQL packages and migration tooling.
- 0.8: HTTP runtime and Qyra Web prototype.
- 0.9: Rust compiler parity, native backend and WebAssembly.
- 1.0: stable specification, installers, LSP, package manager and audited release process.
